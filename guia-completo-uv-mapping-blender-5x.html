PARTE I

Fundamentos

Antes de cortar a primeira costura, é preciso entender o que uma UV realmente é, onde ela vive, e o único inimigo que você combate o tempo todo: a distorção. Esta parte dá a intuição (origami, mapa-múndi, costura), apresenta o UV Editor e estabelece a métrica que governa qualidade — o texel density.

CAPÍTULO 01

O que é UV mapping e por que existe

Uma textura é uma imagem plana — uma grade de pixels num retângulo. Um modelo 3D é uma superfície curva no espaço. UV mapping é a correspondência entre os dois: para cada vértice da malha, um par de coordenadas (u, v) que diz qual ponto da imagem cai ali. Sem esse mapa, o Blender não sabe onde colar a textura — e o resultado é caos.

1.1 — Por que "U" e "V"

As letras X, Y e Z já estão ocupadas pelas coordenadas do espaço 3D. Para nomear os dois eixos do espaço da textura, a computação gráfica pegou as letras anteriores no alfabeto: U (horizontal) e V (vertical). O espaço UV é sempre um quadrado de 0 a 1 em cada eixo — o canto inferior-esquerdo é (0,0), o superior-direito é (1,1). Esse quadrado é o "0–1 space" ou UDIM tile 1001 (mais sobre isso no Cap. 10). Não importa se sua textura é 512×512 ou 8192×8192: as coordenadas UV vão sempre de 0 a 1, e a imagem é esticada para preencher o quadrado.

◆ A definição que resolve tudo

Uma UV é um endereço. Cada canto de cada face da malha guarda um par (u,v) que aponta para um lugar na imagem. "Desdobrar" (unwrap) é o ato de atribuir esses endereços de forma inteligente — de modo que pedaços vizinhos no modelo fiquem vizinhos na textura, e que nada estique. O modelo não muda de forma; só ganha um mapa de como vestir sua superfície.

1.2 — As três analogias que destravam o conceito

UV mapping confunde porque é uma transformação entre dimensões. Três imagens mentais ajudam:

  • O origami ao contrário. Pegue uma caixa de papelão e abra-a numa folha plana. As dobras que você corta com a tesoura são as seams (costuras); a folha aberta é o seu UV layout. Você corta o mínimo para a folha deitar plana sem rasgar nem amassar.
  • O mapa-múndi. A Terra é uma esfera; o mapa na parede é plano. É impossível achatar uma esfera sem distorcer — por isso a Groenlândia parece gigante. Toda projeção é um compromisso entre preservar área e preservar forma. UV é exatamente o mesmo problema, e por isso esferas e formas orgânicas sempre distorcem um pouco.
  • A costura de roupa. Um molde de costura é o tecido plano cortado em peças (mangas, frente, costas) que, costuradas, vestem o corpo 3D. As bordas onde as peças se unem são as seams. Bons costureiros escondem as costuras em lugares discretos — e você fará o mesmo.

1.3 — O que acontece sem UVs (ou com UVs ruins)

Quando você cria uma malha no Blender, ela já vem com um UV map automático — gerado a partir de como o objeto foi feito. Para um cubo ou um plano simples, às vezes basta. Mas assim que você modela algo real, esse UV default fica imprestável: as texturas esticam (stretching), aparecem costuras óbvias, a resolução fica irregular (uma parte nítida, outra borrada). Materiais procedurais que usam coordenadas Generated ou Object (vol. 8 de Shader Nodes) podem dispensar UVs — mas qualquer textura baseada em imagem (um normal map assado, uma foto de madeira, um decal) depende de UVs boas.

▲ O erro de pular UVs

Muita gente modela lindamente, aplica um material procedural no viewport, acha que terminou — e trava na hora de exportar para um game engine ou de assar texturas. Quase tudo no fim do pipeline assume UVs limpas: o baking (vol. 9) projeta o detalhe high-poly para a textura via UV; o texture painting pinta sobre UVs; game engines amostram normal/AO maps pelas UVs. UV não é opcional — é infraestrutura.

CAPÍTULO 02

O UV Editor e o workspace UV Editing

Antes de desdobrar, você precisa do ambiente certo. O Blender tem um workspace dedicado que mostra, lado a lado, o modelo 3D (onde você marca seams e seleciona faces) e o UV Editor (onde os endereços viram um layout que você manipula).

2.1 — Abrir o ambiente

No topo da janela, clique na aba UV Editing. A tela se divide: à esquerda o UV Editor (a imagem 2D), à direita o 3D Viewport já em Edit Mode. A regra de ouro: o UV Editor só mostra as UVs das faces selecionadas no viewport 3D. Se ele aparece vazio, é porque nada está selecionado lá — aperte A no viewport para selecionar tudo.

2.2 — O fluxo mínimo (memorize)

  1. Selecione as faces no viewport 3D

    Entre em Edit Mode (Tab), modo Face (3), e selecione tudo com A.

  2. Marque as seams

    Selecione as arestas onde quer cortar e use Edge ▸ Mark Seam (ou Ctrl+E ▸ Mark Seam). Elas ficam vermelhas. (Cap. 4 ensina onde.)

  3. Desdobre

    Com tudo selecionado, U ▸ Unwrap. As ilhas aparecem no UV Editor.

  4. Confira a distorção

    Ative o overlay de stretch (Cap. 3) e ajuste seams/escala até o azul dominar.

  5. Empacote

    UV ▸ Pack Islands para arrumar tudo dentro do quadrado sem sobrepor (Cap. 7).

2.3 — Os controles do UV Editor

O UV Editor se navega como o viewport: roda do meio para pan, scroll para zoom, G/R/S para mover/girar/escalar ilhas e vértices UV. Os modos de seleção (vértice, aresta, face, ilha) ficam no cabeçalho, ao lado de um ícone extra exclusivo do UV: o UV Sync Selection (o ícone de duas setas no canto superior-esquerdo).

◆ UV Sync Selection: ligado ou desligado?

Com o sync desligado (padrão), o UV Editor só mostra as UVs das faces selecionadas no 3D, e você pode selecionar UVs independentemente da seleção 3D — ideal para trabalhar o layout. Há também o modo Island de seleção (atalho 4) que só existe com sync desligado: clicar seleciona a ilha inteira. Com o sync ligado, a seleção é compartilhada entre 3D e UV (o que você seleciona num aparece no outro) — útil para depurar quais faces correspondem a quais UVs. Aprenda os dois; o desligado é o do dia a dia.

2.4 — A grade de referência e a imagem de teste

O UV Editor mostra o quadrado 0–1 com uma grade. Para avaliar distorção e densidade, carregue uma imagem de teste: no cabeçalho do UV Editor, Image ▸ New, e em Generated Type escolha UV Grid ou Color Grid. Aplique essa imagem como textura no material (Cap. 3) e os quadradinhos da grade revelam na hora qualquer esticamento ou diferença de resolução pela cena.

CAPÍTULO 03

Distorção, escala e texel density

Há dois pecados em UV mapping: distorção (a textura estica ou comprime numa parte) e densidade irregular (uma parte do modelo tem mais pixels de textura que outra, ficando nítida ali e borrada acolá). O dia inteiro de UV é uma luta contra esses dois. Felizmente, o Blender tem ferramentas para medir os dois objetivamente.

3.1 — O overlay de Stretching

No UV Editor, abra o painel Overlays (ícone de dois círculos sobrepostos, canto superior-direito) e ative Display Stretch. Ele colore cada face conforme a distorção: azul = sem distorção (proporção preservada), vermelho = distorção forte. Há dois modos: Area (compara a área da face 3D com a UV) e Angle (compara os ângulos). Mire em manter tudo azul/esverdeado; vermelho é onde a textura vai esticar.

3.2 — Texel density: a métrica que ninguém te conta

Texel density é quantos pixels de textura cabem por unidade de superfície do modelo — geralmente medido em texels por metro (px/m) ou por unidade Blender. É a métrica de "nitidez" da textura. Se um objeto tem 512 px/m e outro tem 2048 px/m na mesma cena, o segundo parecerá 4× mais nítido. Para uma cena coerente, todos os objetos do mesmo tipo devem compartilhar a mesma texel density — senão umas peças ficam borradas perto de outras afiadas.

◆ Como pensar em texel density

A relação é direta: quanto maior uma ilha ocupa no quadrado UV, mais pixels da textura ela recebe, mais nítida fica. Distribuir o espaço UV é distribuir nitidez. Por isso o rosto de um personagem (que a câmera vê de perto) ganha uma ilha grande, e a sola do sapato (que ninguém olha) ganha uma ilha pequena. Texel density é orçamento: você decide onde gastar resolução.

3.3 — Medir e igualar no Blender

O Blender traz isso embutido: ative a extensão UV Tools / Texel Density (ou o add-on clássico "Texel Density Checker"), ou use a régua mental: o Pack Islands moderno tem a opção Scale que, combinada com UV ▸ Average Islands Scale (atalho Ctrl+A no UV Editor), iguala a densidade entre ilhas automaticamente. O fluxo padrão é: desdobrar tudo → Average Islands Scale (todas ficam com a mesma densidade) → Pack Islands (arruma sem mudar a escala relativa).

✔ A receita de densidade uniforme

Selecione todas as ilhas no UV Editor, Ctrl+A (Average Islands Scale) para igualar a densidade, depois UV ▸ Pack Islands para empacotar. Pronto: todas as superfícies recebem a mesma nitidez. Para dar mais resolução a uma parte importante (um rosto), escale aquela ilha manualmente antes do pack — ela passa a ocupar mais quadrado e ganha texels.

PARTE II

Costuras e desdobramento

O coração do UV mapping: decidir onde cortar (seams) e como achatar o que sobrou (unwrap). Esta parte cobre a estratégia de seams para cada tipo de forma, todos os métodos de desdobramento do Blender e quando usar cada um, e as ferramentas finas — pin, live unwrap e endireitar ilhas — que transformam um desdobramento bruto num layout limpo.

CAPÍTULO 04

Seams: onde e por que cortar

Uma seam (costura) é uma aresta marcada onde a malha vai "rasgar" para deitar plana. Toda seam é um compromisso: ela permite achatar sem distorcer, mas cria uma borda visível e uma descontinuidade na textura. A arte das UVs é cortar o suficiente para eliminar distorção, mas o mínimo e nos lugares mais escondidos.

4.1 — Por que seams são necessárias

Lembre do mapa-múndi: não dá para achatar uma esfera sem rasgar. Quanto mais curva a superfície, mais cortes ela precisa. Uma seam diz ao algoritmo de unwrap: "aqui você pode separar — estas duas faces não precisam ficar grudadas no layout". Sem seams suficientes, o unwrap tenta forçar tudo grudado e estica horrores. Com seams demais, você cria ilhas pequenas demais, costuras visíveis e desperdício de espaço.

4.2 — Os três princípios de onde cortar

  • Esconda a costura. Coloque seams onde o olho não vai: a parte de trás de um objeto, dentro de uma fenda, sob o braço de um personagem, ao longo de uma quina já dura. Uma costura numa quina afiada é quase invisível.
  • Siga a forma natural. Cilindros pedem uma costura ao longo do comprimento (como a emenda de uma lata). Membros pedem costuras nas "axilas" e no interior. Quinas duras de hard surface são lugares perfeitos.
  • Corte onde a curvatura muda muito. A transição entre o topo e a lateral de um cilindro, entre a face e o pescoço — onde a superfície "vira" bruscamente, uma seam alivia a distorção.

4.3 — Como marcar e o atalho do dia

Selecione as arestas (modo Edge, 2), depois Ctrl+E ▸ Mark Seam. Para limpar, Ctrl+E ▸ Clear Seam. Truques de seleção que aceleram tudo:

  • Alt+clique seleciona um loop inteiro de arestas — perfeito para a costura em volta de um cilindro.
  • Select ▸ Select Loops ▸ Select Boundary Loop para a borda de uma região de faces selecionadas.
  • Seam from Islands (UV ▸ Seams from Islands): se você já tem um UV (ex.: de um Smart UV Project), isto cria as seams correspondentes — ótimo para depois refinar à mão.
✔ Marcação por ângulo (sharp = seam)

Em hard surface, muitas seams coincidem com as quinas duras. Use Select ▸ Select All by Trait ▸ Select Sharp Edges (ou selecione as arestas já marcadas como Sharp) e marque seam em todas de uma vez. Em geral, toda quina dura é candidata a seam — a descontinuidade da textura ali é mascarada pela própria quebra de iluminação da quina.

CAPÍTULO 05

Os métodos de unwrap

O menu U oferece vários algoritmos de desdobramento. Cada um resolve um problema diferente: alguns respeitam suas seams, outros ignoram tudo e projetam de um ângulo, outros são para casos especiais. Saber qual chamar economiza horas.

5.1 — Unwrap (o principal)

O método padrão. Respeita suas seams e desdobra minimizando a distorção. No painel de redo (canto inferior-esquerdo) você escolhe o algoritmo:

  • Angle Based (ABF) — o padrão; prioriza preservar os ângulos (forma). Melhor para a maioria dos casos, especialmente orgânicos.
  • Conformal (LSCM) — mais rápido, bom para formas simples e mecânicas; tende a preservar ângulos locais mas pode distorcer área.
  • Minimum Stretch (5.x) — variação que busca o menor esticamento global.

Opções importantes: Margin (espaço entre ilhas no auto-pack), Fill Holes, e Correct Aspect (leva em conta a proporção da textura se ela não for quadrada).

5.2 — Smart UV Project

O "desdobrador automático". Ele analisa a malha, corta por ângulo (o Angle Limit define quão diferente duas faces precisam ser para virarem ilhas separadas) e empacota tudo sozinho — sem você marcar uma seam sequer. É excelente para:

  • Hard surface complexo onde marcar seams à mão seria tedioso.
  • Lightmaps e bakes rápidos onde a estética do layout não importa.
  • Um ponto de partida: rode o Smart UV, depois Seams from Islands e refine.

Defeito: as ilhas costumam ser muitas e mal-arrumadas para texturização manual, e as costuras caem onde o algoritmo quis, não onde você esconderia.

5.3 — As projeções diretas

Estas ignoram seams e projetam a partir de uma forma primitiva. Use quando o objeto é aquela forma:

MétodoQuando usar
Cube ProjectionCaixas, prédios, qualquer coisa em planos retos. Projeta das 6 direções.
Cylinder ProjectionLatas, canos, troncos, copos. Desenrola a lateral como rótulo.
Sphere ProjectionBolas, planetas, olhos. Projeção tipo mapa-múndi (distorce nos polos).
Project from ViewProjeta exatamente o que a câmera/viewport vê. Para decals, planos de fundo, projeção de fotos. Versão "Bounds" encaixa no 0–1.

5.4 — Follow Active Quads e Lightmap Pack

Follow Active Quads desdobra uma tira de quads seguindo a forma da face ativa, mantendo todos os quads do mesmo tamanho — perfeito para corredores, estradas, escadas, trilhos, tijolos: superfícies feitas de quads regulares onde você quer a textura fluindo sem distorção. Lightmap Pack gera um UV específico para lightmaps (sem sobreposição, com margem), normalmente num segundo canal de UV (Cap. 13).

✎ Exercício 5.1 — Os três primitivos

Crie um cubo, um cilindro e uma esfera (UV Sphere). Desdobre cada um com o método "errado" e o "certo": tente Sphere Projection no cubo, Cube no cilindro, etc. Carregue a textura UV Grid e observe a distorção em cada combinação. Depois faça o cilindro do jeito certo (seam no comprimento + tampas, Unwrap) e compare com a Cylinder Projection. Note onde cada um coloca a costura.

CAPÍTULO 06

Pin, Live Unwrap e endireitar ilhas

O desdobramento bruto raramente é o final. Estas três ferramentas dão controle fino: pin trava pontos no lugar, live unwrap recalcula em tempo real enquanto você arrasta, e os comandos de endireitar tornam ilhas tortas em retângulos limpos — essencial para texturas que precisam de linhas retas (tijolos, painéis, tecido listrado).

6.1 — Pinning (fixar vértices UV)

Selecione vértices UV e aperte P para fixá-los (ficam vermelhos). Pinos não se movem durante um novo Unwrap — o algoritmo desdobra o resto respeitando esses pontos âncora. Uso clássico: fixar os quatro cantos de uma ilha nos cantos do quadrado 0–1 e re-desdobrar para forçar o preenchimento. Para liberar, Alt+P (Unpin).

6.2 — Live Unwrap

Ative em UV ▸ Live Unwrap no UV Editor. Com ele ligado, sempre que você mover um vértice pinado, o resto da ilha se re-desdobra na hora. Combinado com pins, é mágico para ajustar uma UV orgânica interativamente: fixe alguns pontos-chave, arraste, e veja a malha relaxar em volta sem distorcer.

6.3 — Endireitar e alinhar

As ferramentas que limpam o layout:

  • Follow Active Quads (já visto) — para tiras regulares.
  • UV ▸ Align / Straighten — selecione um loop de vértices UV e alinhe-os no eixo X ou Y, ou use Straighten para deixá-los retos.
  • UV Squares (add-on popular) ou o gesto manual: selecione a borda de uma ilha, alinhe os loops, depois Unwrap com os cantos pinados → a ilha vira um retângulo perfeito.
  • Minimize Stretch (Ctrl+V) — relaxa iterativamente a ilha para reduzir esticamento; segure e mexa o mouse para controlar a intensidade.
✔ O fluxo de uma ilha perfeita

Selecione um loop de borda → Straighten (alinha em linha reta) → repita para o loop oposto → selecione os cantos → P (Pin) → U ▸ Unwrap com Live Unwrap ligado. A ilha relaxa entre os cantos fixados, virando um retângulo com mínima distorção. Use para qualquer superfície que precise carregar linhas retas.

PARTE III

Layout e empacotamento

Desdobrar resolve a distorção; empacotar resolve o aproveitamento. Cada pixel de textura que sobra entre ilhas é resolução desperdiçada. Esta parte cobre o Pack Islands moderno e suas opções, como garantir densidade uniforme no layout final, e as técnicas de economia — simetria, overlapping e stacking — que dobram (ou quadruplicam) o uso do espaço.

CAPÍTULO 07

Packing: o quebra-cabeça das ilhas

Packing é encaixar todas as ilhas dentro do quadrado 0–1 da forma mais compacta possível, sem sobreposição indevida e com uma margem de segurança entre elas. Quanto melhor o pack, mais texels para o modelo — espaço vazio é resolução jogada fora.

7.1 — Pack Islands e suas opções

Selecione tudo e UV ▸ Pack Islands. O motor reescrito do Blender 5.x oferece controles ricos no painel de redo:

OpçãoO que faz
RotationPermite girar ilhas para encaixar melhor. Rotation Method: Any Angle, 90°, ou Axis-Aligned (mantém retângulos retos).
ScaleEscala as ilhas para preencher o quadrado. Desligue se já igualou densidade com Average Islands Scale.
MarginO espaço entre ilhas. Essencial para evitar bleeding (sangramento) no mipmap. Há Margin Method: Scaled, Add, Fraction.
Lock OverlappingTrata ilhas sobrepostas (stacked) como uma só, preservando a sobreposição intencional (Cap. 9).
Shape MethodConcave (encaixa pela forma real — mais apertado) vs Convex/Bounding Box (mais rápido).
PinIlhas com vértices pinados ficam onde estão; o resto packa em volta.

7.2 — Margem: o detalhe que evita o bug

Quando uma textura é reduzida (mipmapping, na distância), pixels de ilhas vizinhas "vazam" um no outro, criando linhas coloridas erradas nas bordas. A margin cria um colchão de segurança. Regra prática: margem proporcional à resolução — em 2K/4K, uma margem de 0.005–0.01 costuma bastar; para mobile com mipmaps agressivos, aumente. O baking (vol. 9) também usa extend/dilate para pintar além das bordas e reforçar isso.

✷ 5.x — o Pack reescrito

O antigo Pack Islands era simples (bounding box, sem rotação fina). O motor moderno do 5.x faz packing por forma côncava com rotação livre, frequentemente superando add-ons pagos de gerações anteriores. Combine Shape Method: Concave + Rotation: Any Angle + Scale para o melhor aproveitamento. Para projetos enormes, add-ons como UVPackmaster ainda oferecem GPU packing e mais controle, mas o nativo já entrega muito.

CAPÍTULO 08

Texel density uniforme na prática

O Capítulo 3 definiu texel density; agora a prática de impô-la num modelo inteiro, com várias peças e materiais. O objetivo: que a textura tenha a mesma nitidez por toda a cena — exceto onde você decidir, conscientemente, gastar mais resolução.

8.1 — O fluxo canônico

  1. Desdobre todas as peças

    Com seams e Unwrap, ou Smart UV onde couber. Não se preocupe com a escala relativa ainda.

  2. Iguale a densidade

    Selecione todas as ilhas no UV Editor (A) e Ctrl+A (Average Islands Scale). Agora todas têm o mesmo número de texels por metro.

  3. Promova as peças importantes (opcional)

    Escale manualmente a ilha do rosto, da face frontal, do detalhe que a câmera vê — elas passam a merecer mais resolução.

  4. Empacote

    Pack Islands com Scale ligado preenche o quadrado preservando as proporções relativas que você definiu.

  5. Verifique

    Aplique a UV Grid: os quadradinhos devem ter o mesmo tamanho em toda a malha (exceto onde você promoveu). Diferenças = densidade desigual.

8.2 — Várias texturas / vários materiais

Se o modelo usa mais de um material, cada material costuma ter seu próprio conjunto de UVs ocupando o quadrado 0–1 inteiro — ou seja, peças de materiais diferentes podem ocupar o mesmo espaço UV sem conflito, porque vão para texturas diferentes. Isso é diferente de UDIMs (Cap. 10), onde um único material se espalha por vários tiles. Decida cedo: um material com tudo num atlas, vários materiais (um por região), ou UDIMs.

▲ A armadilha da escala do objeto

Texel density depende do tamanho real do objeto. Se você esquecer de aplicar a escala (Ctrl+A ▸ Scale, em Object Mode) antes de calcular densidade, o Average Islands Scale usa as dimensões erradas e a densidade fica inconsistente entre objetos escalados de forma diferente. Aplique transformações antes de trabalhar UVs sério — é o mesmo cuidado do baking e da exportação (vol. 9).

CAPÍTULO 09

Simetria, overlapping e stacking

A maneira mais poderosa de ganhar resolução é não desperdiçá-la em coisas repetidas. Se as duas metades de um objeto são iguais, por que dar a cada uma seu próprio espaço de textura? Sobrepor (overlap/stack) ilhas idênticas faz peças repetidas compartilharem os mesmos pixels — multiplicando a densidade efetiva.

9.1 — Simetria de espelho

Um personagem é simétrico: o braço esquerdo é o espelho do direito. Em vez de desdobrar os dois, você desdobra um e sobrepõe o outro por cima (espelhado). Os dois braços passam a amostrar a mesma metade da textura — dobrando a resolução, já que ocupam o espaço de um só. O custo: a textura fica simétrica (uma cicatriz no braço esquerdo apareceria igual no direito). Para hero assets, às vezes se quebra a simetria depois com um detalhe pintado num segundo passo.

9.2 — Stacking de peças idênticas

Um parafuso aparece 20 vezes no modelo. Empilhe (stack) as 20 ilhas exatamente sobre uma só: todas amostram o mesmo pixel, e você só "gasta" um parafuso de espaço. O Pack Islands com Lock Overlapping (ou o add-on de stacking) detecta ilhas idênticas e as mantém empilhadas durante o pack.

9.3 — Quando NÃO sobrepor

  • Lightmaps exigem UVs sem nenhuma sobreposição — cada ponto precisa de um lugar único para guardar sua luz assada (Cap. 13).
  • Bakes de dados de posição/ID (vol. 9) também precisam de UVs únicas.
  • Quando a assimetria importa — um rosto com cicatriz só de um lado, um logo só num ombro. Aí ou se quebra a simetria, ou se pinta o detalhe num canal separado.
✔ A regra do "dois conjuntos de UV"

O padrão profissional para games: UV1 com overlapping e stacking (máxima resolução para as texturas de cor/normal/rough) e UV2 sem sobreposição (gerado por Lightmap Pack ou Smart UV, para a luz assada). Cada um otimizado para seu propósito. Mais sobre múltiplos canais no Cap. 14.

PARTE IV

UDIMs e casos reais

A teoria encontra os fluxos de produção. Esta parte cobre os UDIMs (vários tiles de textura para resolução de cinema), e depois desce a três disciplinas com regras próprias: hard surface e o casamento UV↔bake, UVs orgânicas de personagem, e UVs para games em tempo real — incluindo o segundo canal para lightmaps.

CAPÍTULO 10

UDIMs: tiles de alta resolução

Um único quadrado 0–1 tem um teto de resolução: por maior que seja a textura, há um limite prático (8K, 16K). Para um personagem de cinema que precisa de detalhe extremo em cada poro, isso não basta. UDIMs resolvem isso espalhando as UVs por vários quadrados (tiles), cada um com sua própria textura.

10.1 — Como funciona o sistema de tiles

UDIM significa "U-Dimension". Além do tile padrão (0–1, chamado 1001), você pode colocar ilhas no próximo quadrado à direita (1–2 em U, tile 1002), no seguinte (1003), e assim por diante; a numeração sobe para a próxima fileira em 1011. Cada tile carrega uma imagem separada (ex.: textura.1001.png, textura.1002.png). O Blender e os engines montam tudo automaticamente pela numeração no nome do arquivo.

10.2 — Trabalhar UDIMs no Blender

  1. Crie a imagem como tiled

    No UV Editor, Image ▸ New e marque UDIM Tiles. No painel UDIM Tiles (N) adicione os tiles que vai usar.

  2. Distribua as ilhas

    Mova ilhas para os tiles arrastando-as para os quadrados à direita/acima. O Pack Islands tem opção de empacotar respeitando tiles.

  3. No shader

    O nó Image Texture reconhece UDIMs automaticamente quando a imagem é tiled e o arquivo tem o padrão <UDIM> no nome.

  4. Exporte

    Pinte no Substance/Mari (que adoram UDIMs) ou asse por tile. glTF não suporta UDIMs; USD e formatos de VFX suportam.

▲ UDIM não é para games (em geral)

UDIMs são o padrão de VFX, animação e cinema, onde a pipeline (Maya, Houdini, Mari, USD, RenderMan) os trata nativamente. Game engines de tempo real (Unity, Unreal) tradicionalmente não usam UDIMs — preferem atlas únicos ou texture arrays (Unreal tem suporte parcial via Virtual Textures). Para games, fique no fluxo de 0–1 + múltiplos materiais (Cap. 13). Escolha o caminho pelo destino.

CAPÍTULO 11

UVs para hard surface e o bake

Hard surface (vol. 2) e baking (vol. 9) têm exigências específicas de UV. Aqui a UV não é só para colar uma foto de metal — ela é o destino para onde o detalhe do modelo high-poly será projetado (normal, AO, curvature). UV ruim = bake com costuras, artefatos e desperdício.

11.1 — Seams nas quinas duras

A boa notícia do hard surface: ele tem quinas duras naturais, e elas são lugares perfeitos para seams — a quebra de iluminação da quina esconde a descontinuidade da textura. A regra: marque seam em toda quina dura (as mesmas arestas que receberiam um bevel ou um Sharp). Isso também alinha com o que o normal map espera: ilhas separadas por quinas duras evitam que o bake "sangre" normal entre faces de orientação muito diferente.

11.2 — As regras de UV para um bom bake

  • Sem sobreposição (a menos que intencional e idêntica). Faces sobrepostas no UV recebem o mesmo bake — desastre para normal/AO de peças que não são idênticas.
  • Margem generosa entre ilhas, para o dilate/extend do bake pintar além das bordas sem invadir a ilha vizinha.
  • Ângulos retos quando possível — ilhas alinhadas aos eixos UV produzem normal maps mais limpos e comprimem melhor.
  • Texel density consistente — senão o detalhe assado fica nítido numa peça e borrado noutra.
  • Casar com o ID map — se você vai usar um ID map (vol. 9) para máscaras, ilhas bem separadas por material facilitam.
◆ O elo UV → normal map

Um normal map guarda direções de superfície no tangent space, que é definido pela própria UV. Por isso UV e normal map são inseparáveis: mudar a UV depois de assar invalida o normal map. A ordem correta é sempre UV → bake → texturização. E a convenção de canais (Y+ vs Y−, a "armadilha do verde" do vol. 9) interage com como suas UVs estão orientadas. Trate a UV como decisão final antes de assar.

11.3 — Smart UV como atalho honesto

Para hard surface muito complexo (uma arma com 200 peças), marcar seams à mão é inviável. Smart UV Project com um Angle Limit de ~66° corta nas quinas duras automaticamente e empacota — e como em hard surface as costuras caem nas quinas de qualquer jeito, o resultado costuma ser ótimo para bake. Refine só as peças que a câmera vê de perto.

CAPÍTULO 12

UVs orgânicas (personagem, rosto)

Orgânicos são o caso difícil: superfícies curvas e contínuas, sem quinas para esconder costuras, e regiões (o rosto) que exigem altíssima densidade. As estratégias de seam para um personagem são quase um padrão de indústria — vale conhecê-las.

12.1 — Onde escondem as seams num personagem

O molde clássico de costura corporal:

  • Atrás das orelhas e na linha do cabelo — para a cabeça, escondendo a costura do rosto.
  • Interior dos braços e pernas (a "linha de costura" como numa roupa), descendo pela parte interna.
  • Axilas e virilha — dobras profundas que o olho não acessa.
  • Linha das costas ou da lateral do torso — uma costura central nas costas é discreta.
  • Punhos e tornozelos — para separar mãos e pés em ilhas próprias (que merecem densidade alta).

12.2 — O rosto manda

O rosto é o que a câmera mais vê e onde o olho humano detecta o menor defeito. Dê a ele uma ilha grande e própria, com costura na linha do cabelo e atrás das orelhas, e promova sua texel density (escale a ilha antes do pack, ou dedique um tile UDIM só para a cabeça). Mantenha a simetria para texturizar uma metade, mas reserve um passo final para quebrar a simetria (assimetrias faciais e detalhes são o que dá realismo).

✔ Live Unwrap é seu amigo aqui

Orgânicos distorcem por natureza. Ligue Live Unwrap, fixe (pin) alguns pontos-chave (centro do rosto, pontas dos membros) e use Minimize Stretch (Ctrl+V) para relaxar as ilhas iterativamente. O overlay de stretch (Cap. 3) guia onde ainda há vermelho — adicione uma seam discreta ali se necessário.

CAPÍTULO 13

UVs para games e lightmaps

Tempo real impõe restrições: orçamento de textura apertado, mipmaps agressivos e, muitas vezes, um segundo conjunto de UVs só para a iluminação pré-calculada. Esta é a disciplina mais exigente de packing e organização.

13.1 — As prioridades do game-art

  • Aproveitamento máximo do espaço — cada texel importa no orçamento de VRAM.
  • Overlapping e stacking agressivos em UV1 (peças repetidas, simetria) para esticar a resolução.
  • Margem suficiente para os mipmaps não sangrarem na distância.
  • Atlas — várias peças (ou vários objetos) num único conjunto de texturas, reduzindo draw calls.
  • Padding consistente e ilhas alinhadas aos eixos onde possível (compressão de bloco gosta disso).

13.2 — O segundo canal: lightmap UVs

Engines pré-calculam a iluminação estática e a guardam num lightmap — uma textura de luz por superfície. Para isso, cada ponto da malha precisa de um lugar único no UV (não pode sobrepor, senão duas superfícies guardariam luz no mesmo pixel). Como UV1 costuma ter overlapping para resolução, o lightmap usa um UV2 separado, sem sobreposição.

No Blender: adicione um segundo UV Map (Cap. 14), selecione-o, e use Lightmap Pack ou Smart UV Project com margem. Unity pode gerar lightmap UVs na importação, mas fazê-las no Blender dá mais controle. Unreal usa o "Lightmap UV index" para apontar qual canal é o lightmap.

CanalPropósitoSobreposição?Como gerar
UV0 (UVMap)Cor, normal, roughness — as texturas do materialSim (stack/mirror)Unwrap manual + pack
UV1 (Lightmap)Luz assada (GI estática)Não — únicoLightmap Pack / Smart UV
UV extraDetail maps, decals, máscaras de blendConforme o usoProjeção específica
▲ Ordem dos canais importa na exportação

Engines identificam canais por índice (0, 1, 2…), não por nome. O primeiro UV Map da lista do Blender vira UV0, o segundo vira UV1, etc. Se a ordem estiver trocada, a engine vai amostrar a textura no canal de lightmap (ou vice-versa). Confira a ordem na lista de UV Maps (Object Data Properties) antes de exportar FBX/glTF. Veja a checklist de export no vol. 9.

✎ Exercício 13.1 — Dois canais

Pegue um modelo simples de cenário (uma casinha). Crie UV0 com unwrap manual e packing apertado (pode sobrepor janelas idênticas). Adicione UV1 e gere com Lightmap Pack (sem sobreposição, margem 0.02). Compare os dois layouts: note como o UV1 é mais "espalhado e único" e o UV0 mais "apertado e repetido". Exporte em glTF e confirme que ambos os canais saíram.

PARTE V

Ferramentas e domínio

O ferramental avançado e o olho crítico. Como gerenciar múltiplos UV maps, transferir UVs entre malhas e gerá-las proceduralmente com modifiers e Geometry Nodes, e — o mais importante — como reconhecer as assinaturas visuais de uma UV ruim e consertá-las.

CAPÍTULO 14

Múltiplos UV maps e quem lê cada um

Uma malha pode carregar vários conjuntos de UV ao mesmo tempo, cada um servindo a um propósito. Saber criar, nomear e apontar o shader para o canal certo é o que separa um setup que funciona de um que cola a textura no lugar errado.

14.1 — Criar e gerenciar

Em Object Data Properties ▸ UV Maps, o sinal + adiciona um novo canal (copiando o atual). Você pode renomear (clique duplo), reordenar implícita pela posição, e definir qual é o ativo (o que o UV Editor mostra) e qual tem o ícone de câmera (o usado para render quando o shader não especifica um). O primeiro da lista é o índice 0.

14.2 — Apontar o shader para um canal específico

Por padrão, o nó Image Texture usa o UV ativo de render. Para forçar um canal específico, adicione um nó UV Map (Input ▸ UV Map), escolha o canal pelo nome, e conecte sua saída ao Vector da Image Texture. É assim que você usa, por exemplo, UV0 para a cor e UV2 para um detail map sobreposto. O nó Attribute (com o nome do UV) faz o mesmo via atributo.

UV Map (nome: "UVMap")  ──► Image Texture (cor base)
UV Map (nome: "Detail") ──► Image Texture (detail/decal)  ──► Mix
◆ UVs são atributos

No Blender moderno, um UV map é um atributo do domínio Face Corner (canto de face) do tipo 2D Vector, chamado por padrão UVMap. Isso significa que tudo do sistema de atributos vale: você pode lê-lo e gravá-lo em Geometry Nodes (Cap. 15), transferi-lo com Data Transfer, e vê-lo no Spreadsheet. Entender que UV é "só mais um atributo por canto de face" desmistifica muita coisa — é a mesma natureza dos vertex colors e dos vertex groups (vol. 5).

CAPÍTULO 15

Transferir UVs, modifiers e nodes

UVs não precisam ser sempre desenhadas à mão. Você pode copiá-las de uma malha para outra, projetá-las dinamicamente com modifiers, e gerá-las/modificá-las em Geometry Nodes — útil para variações, retopologia e fluxos procedurais.

15.1 — Transferir UVs entre malhas

Refez a topologia de um modelo e quer reaproveitar as UVs do antigo? Ou tem dez variações do mesmo objeto base? Use o modifier Data Transfer (vol. 5) com Face Corner Data ▸ UVs, ou o operador Object ▸ Link/Transfer Data ▸ Transfer UV Maps (selecione fonte e destino, este por último ativo). Funciona melhor quando as malhas têm formas parecidas; mapeamento por proximidade ou por índice de polígono.

15.2 — UV Project e UV Warp (modifiers)

  • UV Project — projeta UVs a partir de um ou mais "projetores" (objetos empty/camera), como um slide projetado na malha. Ótimo para decals dinâmicos, projeção de vídeo, ou texturizar arquitetura plana sem desdobrar.
  • UV Warp — distorce as UVs existentes a partir do movimento de dois objetos de controle. Usado para animar texturas (uma esteira rolante, água escorrendo, deslocar um padrão) sem tocar no shader.

15.3 — UVs em Geometry Nodes

Geometry Nodes (vol. — Apostila de Geometry Nodes) trata UV como o atributo UVMap do domínio Face Corner. Você pode:

  • Ler a UV com Named Attribute (UVMap, tipo 2D Vector) para usá-la em lógica procedural.
  • Gerar/sobrescrever com Store Named Attribute no domínio Face Corner — por exemplo, projetar UV planar por código, ou criar UV para geometria instanciada.
  • Preservar UVs ao gerar geometria nova (Curve to Mesh já cria UVs próprias; Mesh Boolean precisa de cuidado para manter as UVs dos operandos).
✷ 5.x — UV procedural maduro

Nas versões recentes, manipular UVs em Geometry Nodes ficou direto: o atributo UVMap é exposto como qualquer outro 2D Vector no domínio Face Corner, e nós dedicados (Pack UV Islands, UV Unwrap dentro de GN em builds recentes) permitem desdobramento procedural. Para assets gerados (cabos, trilhos, scatter), isso significa UVs corretas sem passo manual.

CAPÍTULO 16

Diagnóstico e troubleshooting

Saber consertar começa por saber reconhecer. Toda UV ruim deixa uma assinatura visual previsível. Esta é a tabela de socorro do UV mapping — o problema, a causa e a correção.

16.1 — As assinaturas visuais

No UV Editor, o painel Overlays tem três aliados: Display Stretch (distorção, Cap. 3), Display Overlapping (acende ilhas que se sobrepõem indevidamente — vermelho = problema) e Display Modified (mostra o efeito de modifiers nas UVs). Ative-os antes de declarar uma UV pronta.

✔ O teste final dos 30 segundos

Antes de dizer "UV pronta": (1) aplique a UV Grid — quadradinhos uniformes e sem esticar? (2) ligue Display Overlapping — algum vermelho não-intencional? (3) ligue Display Stretch — tudo azul? (4) confira a margem visualmente. (5) confira a ordem dos canais se for exportar. Cinco checagens, trinta segundos, zero retrabalho depois.

Prática

A teoria condensada num projeto completo, e o material de referência para o dia a dia: glossário, atalhos e o resumo das novidades do 5.x.

CAPÍTULO 17

Projeto: UV de um asset completo

Vamos desdobrar um asset hard surface realista — digamos, um rádio portátil (uma caixa com botões, alça cilíndrica, antena, grade de alto-falante). Ele junta todas as técnicas: projeções, seams em quinas, cilindros, stacking de parafusos e densidade uniforme. O fluxo serve para quase qualquer asset.

  1. Prepare

    Aplique todas as transformações (Ctrl+A ▸ All Transforms em Object Mode). Confira normais (Recalculate Outside, Shift+N). Decida: um material só (atlas) — vamos de atlas em 0–1.

  2. O corpo (caixa)

    Marque seams nas quinas verticais traseiras e em volta da base (escondidas). U ▸ Unwrap. Confira: as faces grandes viram retângulos limpos.

  3. A alça (cilindro)

    Seam ao longo da parte interna (que encosta no corpo) + nas extremidades. Unwrap → vira uma tira reta. Use Straighten se entortar.

  4. A antena (cilindro fino)

    Cylinder Projection direto. É fina; vai receber pouca densidade — tudo bem.

  5. Os botões e parafusos (repetidos)

    Desdobre um de cada tipo. Selecione todas as cópias idênticas e empilhe (stack) sobre a primeira. No pack, ligue Lock Overlapping.

  6. A grade do alto-falante

    Se for geometria repetida, stack. Se for um plano com textura/alpha, Project from View de frente.

  7. Densidade uniforme

    Selecione tudo no UV Editor, Ctrl+A (Average Islands Scale). Depois promova o painel frontal (onde estão os controles que a câmera vê) escalando sua ilha ~1.3×.

  8. Pack final

    UV ▸ Pack Islands com Rotation: Any Angle, Shape: Concave, Margin 0.008, Lock Overlapping ON, Scale ON.

  9. Verifique

    UV Grid aplicada: quadradinhos uniformes? Display Overlapping: só os stacks intencionais acendem? Display Stretch: azul? Se sim, pronto para baking (vol. 9) e texturização.

◆ A ordem que nunca muda

Modelar → aplicar transformações → marcar seams → desdobrar → igualar densidade → promover o que importa → empacotar → verificar → (segundo canal se for game) → bake → texturizar. Esta sequência é o esqueleto de qualquer asset. Decorá-la elimina 90% dos problemas de textura que aparecem lá no fim do pipeline.

✎ Exercício 17.1 — Seu próprio asset

Escolha um objeto da sua casa com partes variadas (um controle remoto, uma garrafa térmica, um fone). Modele em blocking simples e aplique o fluxo de 9 passos acima. Meta: layout com >80% de aproveitamento, densidade uniforme (confirmada na UV Grid), e nenhuma costura na face que você apontaria uma câmera. Asse um normal map de um high-poly simples para fechar o ciclo com o vol. 9.

18.3 — Novidades 4.x → 5.x para UV mapping

  • Pack Islands reescrito: packing por forma côncava, rotação em qualquer ângulo, escala por ilha, Lock Overlapping e Pin integrados — frequentemente superando soluções de add-on antigas.
  • UDIMs consolidados: criação de imagens tiled no UV Editor, pack respeitando tiles, e Image Texture reconhecendo a sequência automaticamente.
  • UV como atributo: o canal UVMap é um atributo Face Corner 2D Vector pleno — lido/gravado em Geometry Nodes, transferível por Data Transfer, visível no Spreadsheet.
  • Geometry Nodes: nós e fluxo para gerar/empacotar UV proceduralmente (Pack UV Islands, store do atributo UV).
  • UV Editor: overlays de stretch/overlap refinados, snapping e seleção melhorados, e melhor performance em malhas pesadas.
✔ Onde isto se encaixa na coleção

UV mapping é o volume 7 — a dobradiça do pipeline. Ele recebe a forma da Topologia (vol. 6), do Hard Surface (vol. 2) e do Boolean (vol. 3); serve de base para o Baking (vol. 9), que projeta o detalhe nas UVs; e essas texturas são lidas pelos Shader Nodes e BSDFs e reveladas pela Iluminação (vol. 10). Próximo passo natural: a texturização (texture paint, PBR) que pinta sobre estas UVs, e a Simulação (vol. 8). O manual oficial detalha cada ferramenta em docs.blender.org.
